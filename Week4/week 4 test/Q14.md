# step 1
 
**Task**

Extract the important information from the following customer message.

Customer message:

"Sarah bought shoes last month. The size was wrong. She contacted support twice but still hasn't received the replacement. She is very unhappy and wants a refund."

Return only the important information in a concise list.


### Output

``` 
* **Customer:** Sarah
* **Product:** Shoes
* **Purchase:** Last month
* **Issue:** Wrong size; replacement not received
* **Support contacted:** Twice
* **Sentiment:** Very unhappy
* **Requested action:** Refund

```
# step 2
**Task**

Identify the main problem in the following customer situation.

Customer information:

* Customer: Sarah
* Product: Shoes
* Purchase time: Last month
* Issue: Wrong size
* Previous support contacts: Twice
* Replacement: Not received
* Sentiment: Very unhappy
* Requested action: Refund

Return only the main problem in one concise sentence.

### Output
> Sarah has not received the correct-size shoe replacement despite contacting support twice.


# step 3
**Task**

Customer information:

* Customer: Sarah
* Product: Shoes
* Issue: Wrong size
* Replacement: Not received
* Previous support contacts: Twice
* Customer statement: "She is very unhappy."

Return only the sentiment.

* Product: Shoes
* Issue: Wrong size

* Customer statement: "She is very unhappy and wants a refund."

# step 5
**Task**

Determine whether the following customer situation should be escalated.

Customer information:

* Customer: Sarah
* Product: Shoes
* Issue: Wrong size
* Previous support contacts: Twice
* Replacement: Not received
* Sentiment: Negative
* Requested action: Refund

Return only:

Escalate: Yes/No
Reason: [Concise reason]

### Output
```
Escalate: Yes
Reason: The issue remains unresolved after two support contacts, with strong negative sentiment and a refund request.

```
