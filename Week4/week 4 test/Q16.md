# Prompt
**Task**

Determine whether the following customer message is a complaint.

A complaint is a message where the customer expresses dissatisfaction, reports a problem, or expresses frustration about a product or service.

Return only:

Complaint: Yes/No

Customer message:

<customer_message>
My order arrived damaged and I am very disappointed with the service.
</customer_message>

<customer_message>
The delivery took five days to arrive.
</customer_message>

# Output
 > Complaint: Yes
 > Complaint: No

 # Evaluation
 | Input                       | Expected Result | Actual Result  | Correct? |
| --------------------------- | --------------- | -------------- | -------- |
| Clearly a complaint         | Complaint: Yes  | **Yes** | **Yes** |
| Clearly not a complaint     | Complaint: No   | **No** | **Yes**
