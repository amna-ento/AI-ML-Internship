# Prompt
**Task**

Extract the required information from the following unstructured customer information:

"John Smith purchased a MacBook Pro from our store on August 12. His order number is ORD-9087 and he paid $1,899 using a credit card."

Extract these fields:

* Customer name
* Product
* Order number
* Purchase date
* Amount
* Payment method

Return the information as valid JSON using exactly these fields:

{
"customer_name": "",
"product": "",
"order_number": "",
"purchase_date": "",
"amount": "",
"payment_method": ""
}

Do not add any information that is not present in the original text. Do not include explanations or additional fields.


# Output
```
{
"customer_name": "John Smith",
"product": "MacBook Pro",
"order_number": "ORD-9087",
"purchase_date": "August 12",
"amount": "$1,899",
"payment_method": "credit card"
}
```
