# Prompt
**Task**

Extract the relevant information from the customer message and return it in exactly the JSON structure provided below.

Customer message:

"My order #12345 arrived yesterday, but the screen is broken. I want a replacement."

Return only valid JSON. Do not include explanations, comments, Markdown, or any text outside the JSON object.

Use exactly these four fields:

{
"order_id": "",
"issue": "",
"requested_action": "",
"sentiment": ""
}

# Output
```
{"order_id":"12345",

"issue":"Screen is broken",

"requested_action":"Replacement",

"sentiment":"Negative"}
```

# evaluation
| Criterion                   | Expected Result |
| --------------------------- | --------------- |
| Valid JSON?                 | Yes             |
| Correct `order_id`?         | `12345`         |
| Correct issue?              | Broken screen   |
| Correct requested action?   | Replacement     |
| Correct sentiment?          | Negative        |
| Any extra text?             | No              |
