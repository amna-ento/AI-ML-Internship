# 1. Prompt Version 1
## Prompt
```Tell me about this customer and whether they are happy.```

## Output
```
The customer says they have been using the application for six months and likes the new dashboard because it “looks great.” However, they are unhappy with its performance because it takes almost 10 seconds to load.

Overall: The customer is not fully happy. They appreciate the design but are frustrated by the slow loading time.
```



## improved propmt

Analyze the following customer message and determine the customer's sentiment, main issue, and whether the customer is happy.

Customer message:

"I've been using your application for six months. The new dashboard looks great, but it takes almost 10 seconds to load. Please improve the performance."

Return the result using exactly this structure:

Sentiment:
Main Issue:
Customer Happy:

Do not provide any additional explanation or information outside this structure.
## output
```
Sentiment: Negative
Main Issue: The new dashboard takes almost 10 seconds to load.
Customer Happy: No
```
