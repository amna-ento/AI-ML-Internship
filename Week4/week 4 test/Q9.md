# Prompts

## Prompt 1 

Extract the important information from the following customer feedback.

Customer feedback:

"I've been using your application for six months. The new dashboard looks great, but it takes almost 10 seconds to load. Please improve the performance."

### output 1


- **Usage duration:** 6 months
- **Positive feedback:** New dashboard looks great
- **Main issue:** Dashboard takes almost 10 seconds to load
- **Request:** Improve application/dashboard performance
- **Issue category:** Performance / speed
- **Severity:** Moderate — noticeable impact on user experience

---

## Prompt 2


Classify the following customer feedback into the most appropriate category:

* Bug
* Feature Request
* Question
* Complaint

Customer feedback:

"I've been using your application for six months. The new dashboard looks great, but it takes almost 10 seconds to load. Please improve the performance."

Return only the category name.

### Output 2
 > Complaint



## Prompt 3

Write a short, polite, and professional response to the following customer feedback.

Customer feedback:

"I've been using your application for six months. The new dashboard looks great, but it takes almost 10 seconds to load. Please improve the performance."

Acknowledge the customer's positive feedback, recognize the performance issue, and thank them for reporting it.

Keep the response concise.

### Output 3

```
Thank you for your positive feedback on the new dashboard! We’re sorry about the slow loading time and appreciate you bringing this performance issue to our attention. We’ll look into it and work to improve the experience.

```
