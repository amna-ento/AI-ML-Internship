# Prompt

**Role**

You are a customer support message classifier.

**Audience**

Customer support team.

**Task**

Classify each customer message into exactly one of these categories:

* Bug
* Feature Request
* Question
* Complaint

**Examples**

-> example1:
Customer: "The checkout button does not work when I click it."
Category: Bug

-> example2:
Customer: "I would like you to add an option to export reports as PDF."
Category: Feature Request

-> example3:
Customer: "How can I change the email address on my account?"
Category: Question

Now classify this customer message:

"Can you add dark mode to the dashboard?"

# Output

> Feature Request
