# Prompt
**Role**

You've to act as a customer support message classifier.

**Audience**

Customer support team.

**Task**

Classify the following customer message into exactly one of these categories:

- Order Status
- Refund
- Cancellation
- Product Issue
- Other

Customer message:
"I ordered a phone five days ago, but I still haven't received it. The tracking page says my order is delayed."

Do not provide any explanation. Select only one category.


# Output
> Order Status


# Evaluation 
| Criterion                      | Expected Result                      |
| ------------------------------ | ------------------------------------ |
| Correct category?              | `Order Status`                       |
| Followed output requirement?   | Yes — only the category name         |
| Any unnecessary explanation?   | No                                   |
